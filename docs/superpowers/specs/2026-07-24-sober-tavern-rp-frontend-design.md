# 清醒风格角色扮演对话前端 · 设计规格

> **日期：** 2026-07-24  
> **状态：** 已确认  
> **类型：** 前端原型（纯静态，不含后端）

---

## 1. 项目概述

### 1.1 目标

制作一个 LLM 交互为基础的角色扮演对话游戏前端原型。仿照酒馆（SillyTavern）角色扮演设计，定位为清醒风格、简约大气的单页 Web 应用。

### 1.2 核心约束

- **纯前端原型** — 不涉及后端开发，不含 API 调用逻辑
- **全中文化** — 除 logo 和视觉设计元素外全部中文
- **禁止 emoji** — 使用 SVG ICON 替代
- **非占位符** — 基于真实角色卡数据（qhl.json）填充内容
- **内部通知** — 使用自建 toast/通知组件，不使用浏览器 alert

### 1.3 技术栈

| 类别 | 选型 |
|------|------|
| 标记语言 | HTML5（语义化标签） |
| 样式 | 纯 CSS（CSS Variables + Flexbox/Grid + Transitions/Animations） |
| 脚本 | 原生 JavaScript（ES2020+），零依赖 |
| 外部资源 | 仅字体（Google Fonts 或自托管无衬线字体） |

## 2. 视觉设计

### 2.1 色彩系统

冷峻深色系 — 深灰/炭黑基底，冷白文字，低饱和度冰蓝/雾绿点缀。

| 用途 | 色值 | 说明 |
|------|------|------|
| 页面背景 | `#141619` | 最深基底 |
| 面板/卡片背景 | `#1a1d23` | 主要容器 |
| 次级面板 | `#20242a` / `#252830` | 嵌套容器、悬浮卡片 |
| 边框/分割线 | `#2d3140` | 微妙分割 |
| 主文字 | `#e8eaed` | 标题、当前对话 |
| 次级文字 | `#c8ccd4` | 正文 |
| 辅助文字 | `#8b95a5` / `#9aa4b2` | 标签、描述 |
| 弱化文字 | `#6b7583` | 时间戳、提示 |
| 主强调色 | `#7eb8da` | 冰蓝 — 选中态、发送按钮、链接 |
| 辅助强调色 | `#6fc98f` | 雾绿 — 在线状态、成功提示 |
| 警告色 | `#c46b6b` | 删除确认、错误提示 |
| 用户气泡背景 | `#1e3a4a` | 深蓝底 |
| 角色气泡背景 | `#252830` | 深灰底 |

### 2.2 字体

- 正文：系统原生优化的现代无衬线字体栈（`"Segoe UI", "PingFang SC", "Microsoft YaHei", "Noto Sans SC", system-ui, -apple-system, sans-serif`）
- 等宽（代码/JSON）：`"JetBrains Mono", "Fira Code", "Cascadia Code", "Consolas", monospace`
- 排版注重行高（1.6–1.8）和字间距，避免浏览器默认样式

### 2.3 图标

全部使用内联 SVG 图标，尺寸控制在 12–24px。常用动作图标集：发送、设置、编辑、删除、折叠/展开、关闭、搜索、历史、书签、通知、警告、成功、复制、刷新等。

### 3.1 主页面结构（三栏 + 底部）

├────────────┬──────────────────────────────┬──────────────────┤
│ 左侧角色栏  │       中央聊天区域            │  右侧 AI 控制面板  │
│ (220px)    │       (flex: 1)              │  (280px)         │
│            │                              │  [角色设定]       │
│ 头像       │  ┌──────────────────────┐    │  [世界书]         │
│ 名称       │  │ 叙述段落（居中灰斜体）│    │  [对话设置]       │
│ 状态指示   │  ├──────────────────────┤    │                  │
│ 好感度     │  │ 角色气泡（左对齐）    │    │                  │

│ 场景标签   │  ├──────────────────────┤    │                  │
│ 角色记忆   │  │ 用户气泡（右对齐）    │    │                  │

### 3.2 左侧角色栏（220px 固定宽度）

**单人模式（不显示多角色切换标签）。基于 qhl.json 状态块 `<status_block>` 结构设计，共 4 个折叠模块、22 个字段。**

#### 头像区（始终可见）

- 角色头像 — 64px 圆形，线性渐变背景 + SVG 人物轮廓占位
- 角色名称 — 16px 加粗
- 昵称 + 年龄 + 星座 — 10px 次级字色
- 好感度精简条 — 箭头（↑↓→）+ 数值 + 变化值 + 2px 进度条

#### 模块一：基本信息（默认展开）

| 字段 | 说明 |
|------|------|
| 名称 | 角色姓名 |
| 位置 | 当前地点，格式「地名·具体位置」 |
| 好感度 | 箭头 ↑↓→ + 0–100 整数，动态增减 |
| 变化原因 | 好感度变化的原因简述 |
| 周围角色 | 其他在场角色的状态简述 |

#### 模块二：外观（默认折叠，摘要显示「上衣 + 下装」）

| 字段 | 说明 |
|------|------|
| 表情 | 面部表情，≤15字 |
| 身体 | 声形色味感整体描写，≤15字 |
| 外套 | 最外层衣物 |
| 上衣 | — |
| 内衣 | — |
| 下装 | 裙/裤 |
| 内裤 | — |
| 袜子 | — |
| 鞋子 | — |
| 配饰 | — |

服装条目需根据剧情实时更新（脱衣、换装等）。

#### 模块三：心理（默认折叠，摘要显示「下一步计划」首句）

| 字段 | 说明 |
|------|------|
| 内心想法 | 不对玩家说出口的真实心理，斜体引用块样式 |
| 当前动作 | 正在做的肢体动作，菱形 ◆ 前缀 |
| 下一步计划 | 接下来准备做的事，菱形 ◆ 前缀 |

内心想法必须与角色说出口的话不同，反映真实心理。

#### 模块四：角色档案（默认折叠）

| 字段 | 说明 |
|------|------|
| 年龄 | — |
| 星座 | — |
| 体征 | 身高/体重 |
| 性格 | 摘要标签式 |
| 喜好 | 摘要标签式 |

**数据来源：** qhl.json 的 `name` / `personality` / `scenario` 字段，以及 LLM 实时输出的 `<status_block>` XML 块。

### 3.3 中央聊天区域

**剧本流 + 微信气泡融合布局。**

#### 消息类型与样式

| 类型 | 标记 | 样式 | 对齐 |
|------|------|------|------|
| 角色动作/心理 | `*...*` | 斜体 · `#8b95a5`（角色侧）/ `#7ea8c4`（用户侧） | 按气泡 |
| 角色对话 | `"..."` | 正常 · `#d4d8df`（角色侧）/ `#d0dce6`（用户侧） | 按气泡 |
| 叙述段落 | 无标记 | 居中 · 细灰斜体 · 左侧 2px 装饰线 | 居中 |
| 角色气泡 | — | `#252830` 背景 · 16px 圆角 · 左下直角 · 左对齐 | 左 |
| 用户气泡 | — | `#1e3a4a` 背景 · 16px 圆角 · 右下直角 · 右对齐 | 右 |

#### 气泡行为

- 每条气泡顶部显示发送者标签（角色名或"你"），10px 小字
- 角色气泡最大宽度 70%，用户气泡最大宽度 60%
- 连续同角色消息的间距 8px，切换角色时 20px
- 新消息进入时平滑滚动到底部（smooth scroll）

### 3.4 右侧 AI 控制面板（280px）

**标签页切换式，默认激活"角色设定"。**

#### 标签页 1：角色设定

- 基本信息（名称/昵称/年龄/星座）— 可编辑输入框
- 性格特质 — 文本域
- 喜恶偏好 — 文本域
- 背景经历 — 文本域
- 关系描述 — 文本域

数据预填充自 qhl.json。每条字段右侧有编辑图标，点击切换为编辑态。

#### 标签页 2：世界书

**条目列表（可折叠展开）：**

每条条目包含：

| 字段 | 类型 | 说明 |
|------|------|------|
| 条目名称 | 文本输入 | 唯一的条目标识 |
| 关键词 | 标签组（可添加/删除） | 触发匹配词，支持多词 |
| 内容 | 文本域 | 触发后注入的设定文本 |
| 权重 | 数字输入（0–999） | 排序优先级 |
| 插入位置 | 下拉选择（11 种） | 见下方详细说明 |
| 触发条件 | 下拉选择 | 关键词匹配 / 始终触发 / 概率触发 |
| 状态 | 开关 | 启用 / 禁用 |

**插入位置完整选项（11 种）：**

| # | 插入位置 | 分组 | 说明 |
|---|---------|------|------|
| 1 | 角色定义之前 | 提示词 | 插入角色描述和场景之前，适度影响 |
| 2 | 角色定义之后 | 提示词 | 插入角色描述和场景之后，影响更大 |
| 3 | 示例消息之前 | 提示词 | 解析为示例对话块，插入示例之前 |
| 4 | 示例消息之后 | 提示词 | 解析为示例对话块，插入示例之后 |
| 5 | 作者注记顶部 | 注记 | 插入作者注记内容顶部 |
| 6 | 作者注记底部 | 注记 | 插入作者注记内容底部（注记频率=0时忽略） |
| 7 | @ 深度 D | 深度 | 指定聊天深度位置，需额外输入 D 值 |
| 8 | ⚙️ 系统角色消息 | 角色 | 以 system 角色插入 |
| 9 | 👤 用户角色消息 | 角色 | 以 user 角色插入 |
| 10 | 🤖 助手角色消息 | 角色 | 以 assistant 角色插入 |
| 11 | 输出口 | 宏 | 不自动注入，通过 `{{outlet::名称}}` 宏调用 |

**条目操作：** 新建 · 编辑 · 删除（含确认提示框） · 导入 · 导出 · 拖拽排序。

**特殊逻辑：**
- 选中 `@深度D` 时额外显示深度值数字输入框
- 选中 `输出口` 时额外显示出口名称输入框
- 选中示例消息位置时显示行为规则提示（逐渐推出/始终保留/完全禁用）
- 选中作者注记位置时显示禁用警告（当注记频率=0时）

#### 标签页 3：对话设置

- Temperature 滑块（0–2）
- Top-P 滑块（0–1）
- 最大回复 Token（数字输入）
- 上下文长度（数字输入）
- 作者注记频率（数字输入，0=禁用）
- 流式输出开关

### 3.5 底部输入栏

**左到右排列：**

1. **输入框** — 自适应高度（2–6行），placeholder "输入你的回复…"
2. **Token 计数器** — 实时显示 "Token: 0/4096"
3. **操作菜单按钮** — 点击展开菜单：重生成 / 继续写 / 撤回最后一条 / 清空对话
4. **发送按钮** — 冰蓝主题色，圆形，内含发送 SVG 图标

## 4. 模态框与独立页面

### 4.1 角色卡管理

- 角色卡列表（本地存储的角色卡缩略预览）
- 导入角色卡（支持 JSON 文件拖拽或选择上传）
- 导出当前角色卡
- 删除角色卡（含确认）

### 4.2 角色卡编辑器

- 可视化表单编辑角色卡字段
- 字段与 SillyTavern v3 格式对应：name / description / personality / scenario / first_mes / mes_example / talkativeness / tags
- JSON 源码切换视图（并排或切换）
- 保存 / 另存为

### 4.3 对话历史记录

- 时间线列表（按会话分组）
- 每条会话显示：角色名、日期、首条消息摘要
- 点击展开完整对话（只读浏览模式）
- 删除 / 导出单条会话

### 4.4 对话书签收藏

- 在对话中标记精彩段落
- 书签列表：角色名、摘录文本、跳转按钮
- 删除书签

### 4.5 全局设置

- 主题选择（预设色彩主题，至少深色/更暗两套）
- 字体大小调节（小/中/大）
- 气泡样式切换（当前风格 / 紧凑风格）
- 键盘快捷键列表
- 数据管理（清空所有本地数据，含二次确认）

## 5. 交互与动效

### 5.1 微交互动画

| 触发 | 效果 | 时长 |
|------|------|------|
| 按钮悬停 | 背景色渐变 + 轻微缩放（scale 1.02） | 150ms ease-out |
| 标签页切换 | 下划线滑动 + 内容区淡入 | 200ms ease |
| 条目展开/折叠 | 高度过渡 + 箭头旋转 90° | 250ms ease |
| 模态框打开 | 背景模糊 + 框体淡入 + 轻微上移 | 200ms ease-out |
| 模态框关闭 | 淡出 + 轻微下移 | 150ms ease-in |
| 消息入场 | 从下方滑入 + 透明度渐变 | 300ms ease-out |
| 发送按钮 | 悬停发光效果（box-shadow glow） | 200ms |
| 成功通知 | 右侧滑入 + 自动滑出 | 300ms in / 3s 后 300ms out |
| 删除确认 | 红色边框脉冲一次 | 400ms |

### 5.2 通知系统

自建 Toast 通知组件：
- 位置：右上角固定定位
- 类型：成功（绿）、警告（黄）、错误（红）、信息（蓝）
- 图标：对应 SVG 图标
- 内容：标题 + 描述文字
- 行为：3 秒自动消失，可手动点击关闭
- 支持多条堆叠显示（最多 3 条同时可见）

## 7. 浏览器兼容性与性能

### 7.1 目标浏览器

- Chrome 100+
- Edge 100+
- Firefox 100+
- Safari 16+

### 7.2 性能指标

- 页面首次渲染 < 1s（零外部 JS 依赖）
- CSS 动画仅使用 `transform` 和 `opacity`（GPU 加速，避免 layout thrashing）
- 对话渲染使用 DocumentFragment 批量插入（避免逐条重排）
- 虚拟滚动（对话超过 500 条时启用）

# 插入位置 分组 说明
1角色定义之前提示词插入在角色描述和场景之前，适度影响
2角色定义之后提示词插入在角色描述和场景之后，影响更大
3示例消息之前提示词解析为示例对话块，插入示例之前
4示例消息之后提示词解析为示例对话块，插入示例之后
5作者注记顶部注记插入作者注记内容顶部（注记频率=0时忽略）
6作者注记底部注记插入作者注记内容底部（注记频率=0时忽略）
7@ 深度 D深度指定聊天深度位置，需额外输入深度值D
8⚙️ 系统角色消息角色以 system 角色插入
9👤 用户角色消息角色以 user 角色插入
10🤖 助手角色消息角色以 assistant 角色插入
11输出口宏不自动注入，通过 {{outlet::名称}} 宏手动调用
